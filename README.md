# WINE AI

واجهة WINE AI متكاملة للمحادثة والكتابة والبرمجة، مبنية على محرك Gemini scraper المرفق داخل المشروع.

## المزايا
- واجهة عربية افتراضيًا ومتجاوبة مع الهاتف والكمبيوتر.
- محادثات جديدة وسجل محلي للمحادثات على نفس المتصفح.
- وضع زائر بتوكن جلسة موقّع من الخادم.
- تسجيل حساب/دخول بالبريد وكلمة المرور عبر MySQL.
- محرك Gemini scraper موجود داخل `src/lib/scrap/ai/gemini.js` ومربوط بمسار `/api/chat`.
- إنشاء صور من وصف المستخدم عبر OpenAI Images API في مسار مستقل `/api/images`، مع إبقاء المفتاح على الخادم فقط.
- حماية أساسية لمعدل الطلبات والتحقق من جلسات JWT.
- أيقونة المشروع `icon.png` في جذر المشروع.

## مهم بخصوص مفاتيح API
لا تحتاج إلى Gemini API Key أو OpenAI API Key. المشروع يستخدم محرك الـ scraper المرفق. لكن هذا المحرك يعتمد على واجهات ويب خاصة وغير موثقة لدى Google؛ قد تتغير أو تتوقف، ولا يوجد ضمان لاستمرارية عمله أو توافقه مع كل أنواع الطلبات.

## المتطلبات
- Node.js 20 أو أحدث.
- `JWT_SECRET` بطول 32 حرفًا على الأقل لتشغيل جلسات الزوار.
- MySQL لتفعيل التسجيل والدخول وحفظ محددات المعدل. لا تحتاج قاعدة البيانات لتوفير مفتاح لمزود الذكاء الاصطناعي، لكن المشروع الحالي يستورد MySQL في مسارات الخادم.

## تشغيل محلي
1. انسخ `.env.example` إلى `.env`.
2. ضع قيمة عشوائية طويلة في `JWT_SECRET`.
3. جهّز قاعدة MySQL ونفّذ `database/schema.sql`، ثم املأ بيانات الاتصال في `.env`.
4. نفّذ:

```bash
npm install
npm start
```

5. افتح `http://localhost:3000`، وافحص `http://localhost:3000/api/health`.

## النشر على GitHub وVercel
1. ارفع محتويات المجلد إلى جذر مستودع GitHub (لا ترفع مجلدًا متداخلًا إضافيًا).
2. من Vercel اختر **Add New → Project** ثم استورد المستودع.
3. اختر Framework Preset: **Other**. اترك Build Command فارغًا، ولا تحتاج Output Directory مخصصًا.
4. أضف Environment Variables التالية في إعدادات المشروع على Vercel:
   - `JWT_SECRET`: سلسلة عشوائية قوية لا تقل عن 32 حرفًا.
   - `DB_HOST`
   - `DB_PORT` (غالبًا `3306`)
   - `DB_USER`
   - `DB_PASSWORD`
   - `DB_NAME`
   - `DB_SSL` (`true` إذا كان مزود قاعدة البيانات يتطلب SSL، وإلا `false`)
5. نفّذ `database/schema.sql` على قاعدة البيانات.
6. أعد النشر، ثم افتح `/api/health`. جرّب بدء محادثة زائر، وبعدها جرّب التسجيل إذا كانت قاعدة البيانات مضبوطة.

## متغيرات البيئة
راجع `.env.example`. لا تضع أي أسرار في `app.js` أو ملفات الواجهة، ولا ترفع `.env` إلى GitHub.

## حدود النسخة الحالية
- المحادثات محفوظة محليًا في المتصفح، وليست متزامنة بين الأجهزة.
- تسجيل الحسابات يحتاج MySQL جاهزًا.
- عدادات الاستخدام/الحماية تعتمد على قاعدة البيانات، وبعضها يعمل بوضع السماح عند تعذر اتصال قاعدة البيانات.
- محرك Gemini scraper غير رسمي وقد يتعطل إذا غيّرت Google واجهاتها.
- لا توجد في هذه النسخة مزامنة سحابية للمحادثات أو ميزات Vision/Claude مفعّلة.

## هيكل مهم
- `index.html`, `styles.css`, `app.js`: الواجهة.
- `icon.png`: أيقونة المشروع.
- `api/chat.js`: نقطة محادثة الذكاء الاصطناعي.
- `api/guest.js`: جلسات الزوار.
- `api/images.js`: إنشاء الصور مع التحقق من الجلسة وحد يومي قدره 5 صور.

## إعداد إنشاء الصور
أضف `OPENAI_API_KEY` كمتغير بيئة مشفّر في Vercel (Production وPreview عند الحاجة). لا تضع المفتاح في `app.js` أو HTML أو أي ملف عام. يستخدم المسار `gpt-image-2.5-flare` افتراضياً ويمكن تغييره عبر `OPENAI_IMAGE_MODEL`. إنشاء الصور غير متاح حتى تضيف مفتاح OpenAI صالحاً إلى إعدادات المشروع. راجع [توثيق OpenAI Images API](https://developers.openai.com/api/reference/resources/images/methods/generate).
- `api/auth.js`: تسجيل الحسابات والدخول.
- `api/health.js`: فحص الخدمة.
- `src/lib/scrap/ai/gemini.js`: محرك Gemini scraper المرفق.
- `database/schema.sql`: مخطط قاعدة البيانات.
